# SBN Solr Registry Image

This directory is the SBN-owned image overlay for the legacy Solr registry.
It keeps the image build outside the upstream-style Maven modules while leaving
deployment to Archive Loader.

The Docker image is secret-free. It contains the registry manager distribution,
Solr configsets, schemas, XSLT, and startup/bootstrap scripts. Credentials and
`security.json` are generated by the Archive Loader deployment at runtime.

## Build Machine

Build the Maven release and local image from the repository root:

```bash
deploy/sbn-solr/scripts/build-image.sh
```

The script automatically loads `deploy/sbn-solr/.env` when it exists:

```env
REGISTRY_IMAGE=en-registry-solr:local
SKIP_MAVEN=false
```

Set `REGISTRY_IMAGE` there to tag for a registry, then build and push:

```bash
deploy/sbn-solr/scripts/build-image.sh
docker push ghcr.io/sbn-psi/en-registry-solr:5.2.0-sbn1
```

For an offline host, save the image:

```bash
docker save en-registry-solr:local -o en-registry-solr-local.tar
```

## Build Variables

`deploy/sbn-solr/scripts/build-image.sh` loads `deploy/sbn-solr/.env` and reads only:

- `REGISTRY_IMAGE`: optional Docker image tag. Defaults to `en-registry-solr:local`.
- `SKIP_MAVEN=true`: optional shortcut when `registry-mgr-legacy/target` already contains the binary tarball.

Deployment variables such as `SOLR_ADMIN_PASSWORD`, `SOLR_READER_PASSWORD`,
`SOLR_PORT`, `SOLR_HEAP`, and `security.json` belong in the Archive Loader
repository, not here.

## Deployment

Deploy this image from the Archive Loader repository. Archive Loader provides
the Compose services, generated runtime credentials, Solr `security.json`,
collection bootstrap, health checks, and bind-mount-to-volume migration helper.
